# Planet Parade privacy

**Planet Parade collects nothing.** There are no accounts, ads, analytics, trackers or cookies.

- **Everything stays on the device.** Settings (language, voice, number range, play time) and the grown-ups' "Today" summary are saved in the browser's local storage on that device only. Clearing the browser's site data removes them.
- **No network during play.** The game is a single file. Once it's loaded (or installed as an app), it works offline and doesn't contact any server. When it's hosted on a website, the only requests are for the game's own files.
- **Voices.** Spoken words use the device's built-in text-to-speech. Some devices use online "natural" voices provided by the operating system or browser. That's a device setting, and the game sends nothing itself.
- **Recordings stay local.** Recording Studio clips are saved in this browser's IndexedDB on this device. They leave the device only if a parent taps **Export recordings** and chooses where to save the file. The microphone is used only while a parent is recording in the Studio.
- **Children.** Planet Parade is designed for young children and asks for no personal information. The game shows no links, purchases or outside content.

Questions: contact the person who shared this game with you.
